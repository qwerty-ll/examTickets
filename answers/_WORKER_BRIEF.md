# Инструкция исполнителю: ответы на экзаменационные вопросы по старославянскому языку

Источник: Хабургаев Г. А. «Старославянский язык». М., «Просвещение», 1974.
PDF: `/home/user/examTickets/Khaburgaev_Staroslavyanskiy_yazyk_24MB.pdf` (434 PDF-стр.). Это **скан**.

## Задача

Для каждого вопроса из твоей группы написать **исчерпывающий, лаконичный, без воды** ответ **строго по учебнику**.
Ничего не придумывать. Каждое утверждение, правило, форма, пример и цифра должны быть найдены тобой в книге.
Если учебник чего-то не даёт, написать об этом прямо одной строкой «В учебнике не рассматривается», ничего не додумывая
из общих знаний. Интернет не использовать.

## Как работать (строго)

1. Работай над вопросами **по очереди**. Для каждого: найди его страницы, прочитай их, составь ответ, **сразу запиши файл**
   `/home/user/examTickets/answers/QNN.md` (NN = две цифры номера), только после этого переходи к следующему вопросу.
2. Каждый ответ строй **только** из страниц, относящихся к этому вопросу. Не переноси текст из ответа на соседний вопрос.
   Допустимо повторять один и тот же факт, если он нужен в обоих ответах, но каждый раз заново проверяя его по странице.
3. Читай **все** страницы диапазона вопроса, не только «основные». Пропущенный пункт хуже лишнего.
4. Читай листы партиями, не открывай одну и ту же страницу повторно без нужды.
5. Старославянские формы записывай **в Unicode с сохранением графики книги**: ѣ ѫ ѧ ѭ ѩ ѥ ꙗ ѵ ѹ ꙋ ъ ь ѿ ѕ и т. д.;
   транскрипции в [ ], праформы со `*`; надстрочные знаки и диакритику не теряй. Ничего не «нормализуй» к современной кириллице
   (ѣ → е, ѫ → у и т. п. запрещено). Если не уверен в написании буквы, пиши как видишь и помечай `⟦?⟧`.
6. Не перепечатывай длинные куски авторской прозы: пересказывай суть сжато, но **сохраняй все факты**: каждое правило, условие,
   исключение, оговорку («как правило», «в отдельных памятниках»), каждый пример и каждую цифру. Короткие цитаты допустимы.
   Таблицы парадигм (склонение, спряжение) воспроизводи **полностью**, строка в строку.
7. Не добавляй то, о чём вопрос не спрашивает. Но то, о чём спрашивает, давай полностью: у многих вопросов несколько частей
   (читай формулировку внимательно, каждая часть должна быть отражена).
8. Если в вопросе есть пункт, который учебник покрывает на странице вне указанного диапазона, найди её по оглавлению/Grep и прочти.

## Формат файла `answers/QNN.md`

```
## Вопрос N. <полный текст вопроса, как дан>

**Суть ответа.** 2–4 предложения: главное, что нужно сказать на экзамене.

### <Часть 1 вопроса> (§ …, с. …)
- пункты / короткие абзацы
| таблицы для парадигм и сопоставлений |

### <Часть 2 …>
…

*Источник: § …, с. …–….*

**Отметки:** ⟦?⟧ места с сомнительным чтением (страница), либо «нет».
```

Правила оформления: заголовки `###`; жирным ключевые термины при первом упоминании; предложения короткие; абзацы ≤ 3 предложений;
списки только для параллельных пунктов; таблица там, где материал табличный (парадигмы, сопоставления, классификации);
ссылки вида (§ N, с. X) после каждого смыслового блока. Печатные номера страниц, не PDF-номера, в ссылках.
Язык русский. Без эмодзи. Без вступлений вроде «В данном ответе рассматривается».

## Самопроверка перед сдачей каждого вопроса

- Все части вопроса отражены? (перечитай формулировку и пройди по ней пунктами)
- Каждая старославянская форма сверена с картинкой страницы? Каждая таблица сверена построчно?
- Нет ли утверждений, которых нет в книге? Нет ли смешения с другим вопросом?
- Нет ли в ответе слов из OCR-мусора (`^`, лишних пробелов внутри слов, латиницы вместо кириллицы)?

## Финальный отчёт (≤ 12 строк)

Список записанных файлов; какие PDF-страницы прочитаны; список мест `⟦?⟧`; что из вопроса учебник не покрывает; сомнения.
Сами ответы в отчёт **не** вставляй.
