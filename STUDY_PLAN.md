# План изучения учебника

Источник: Хабургаев Г. А. «Старославянский язык». М., «Просвещение», 1974.
Файл: `Khaburgaev_Staroslavyanskiy_yazyk_24MB.pdf` (434 PDF-страницы, 432 печатные, 443 параграфа).

## Что представляет собой PDF

- Это **скан** 1974 года с приклеенным OCR-слоем. Слой терпим для прозы и безнадёжен
  для старославянских форм, сносок со старыми буквами, греческих вставок, реконструкций
  с `*` и надстрочных знаков. Примеры порчи: `постаЕиты`, `виД'Ьл'ь`, `пр^ д ам к и`.
- В скане есть карандашные подчёркивания и обводки предыдущего читателя. Это не часть книги.
- Сдвиг PDF-страница → печатная страница не постоянный: +1 в начале, +2 ближе к концу
  (вклейки). Поэтому в индексе всегда пишутся **обе** нумерации.
- Структура: Введение; Фонетика; Морфология (имя существительное, местоимения, имя
  прилагательное, числительные, глагол, наречия, служебные слова); Синтаксис.
  Единица деления везде — параграф (§ 1–443). В конце разделов есть библиографии.

## Принципы

1. **Первоисточник — изображение страницы. OCR только для навигации.**
   Любая старославянская форма, таблица склонения или спряжения, реконструкция
   и сокращение сверяются по картинке.
2. **Ничего не выбрасывать.** Допускается сжатие формулировок, но не фактов: каждое правило,
   каждое исключение, каждая форма в таблице, каждая оговорка («как правило»,
   «в отдельных памятниках») и каждая отсылка к памятнику остаются в заметках.
3. **Заметки не заменяют книгу.** Они помогают быстро найти и понять нужное место.
   Каждый пункт заметок несёт ссылку `§ / PDF-стр. / печ. стр.`, и при решении задач
   нужные страницы открываются заново по картинке.
4. **Сомнительное помечается**, а не угадывается: `⟦?⟧` рядом с чтением, которое не удалось
   подтвердить (с указанием страницы).
5. **Исходные символы не подменяются.** См. «Символы» ниже.

## Технология чтения

`tools/tile.py PDF ПЕРВАЯ ПОСЛЕДНЯЯ ВЫХОД [по_сколько=2] [dpi=170]`

- рендер 170 dpi, оттенки серого;
- автообрезка пустых полей (на сканах текст занимает ~60 % листа);
- по 2 страницы на лист рядом, над каждой подпись `PDF p.N`;
- результат ~1570×1270 px: старые буквы читаются уверенно (проверено на PDF 90–93).

Решение «по несколько страниц на лист» взято из совета пользователя: меньше обращений,
и это снижает расход. При этом 3 и более страниц на лист не используются, потому что
мелкие знаки (ѣ, ѫ, ѧ, ъ/ь, надстрочные) перестают быть надёжно различимы.

## Проходы

1. **Карта.** По оглавлению (PDF 430–434) и по картинкам: § → PDF-страница → печатная страница.
   OCR-маркеров § находит только около половины, поэтому карта дополняется при чтении.
2. **Чтение по порядку**, листами по 2 страницы, блоками ~10–20 страниц.
   После каждого блока сразу пишется файл заметок `notes/NN_<раздел>.md` и делается коммит.
   Заметки пишутся по ходу, не «потом по памяти».
3. **Индексы** (по готовым заметкам):
   - `notes/INDEX.md`: § → страницы → файл заметок;
   - `notes/TERMS.md`: термины и где определены;
   - `notes/TABLES.md`: все парадигмы и таблицы с адресами;
   - `notes/CHARS.md`: символы книги.
4. **Контроль.** Нумерация § без пропусков. В каждом блоке одна страница сверяется повторно
   вслепую. Отдельно перечитываются места с таблицами, потому что именно там цена ошибки выше всего.

## Формат заметок

```
### § N. Название (PDF стр. X, печ. Y)
- Суть: ...
- Правила / закономерности: (все, с условиями и исключениями)
- Примеры: старославянская форма — перевод/русск. соответствие, реконструкция *...
- Таблица: (полностью, строка в строку)
- Отсылки: к другим §, памятникам, учёным
- ⟦?⟧ сомнительные места
```

Длинные куски авторской прозы не перепечатываются. Заметки пересказывают суть и сохраняют
все формы, цифры, имена и условия.

## Символы

Старославянские формы записываются в Unicode с сохранением **графики книги**. Заготовка
(уточняется по мере чтения, в `notes/CHARS.md` фиксируется, как каждая буква выглядит в книге):
`ѣ ѫ ѧ ѭ ѩ ѥ ꙗ ѵ ѡ ѹ ꙋ ѕ ѳ ѯ ѱ ъ ь` и транскрипции вроде `ǫ ę ě ȯ ь̆ й`.
Глаголические буквы записываются блоком Glagolitic (U+2C00…). Если буква книги не имеет
однозначного Unicode-эквивалента, она описывается словами и помечается `⟦?⟧`.
Ни при каких условиях не «нормализуется» к современной кириллице (ѣ → е, ѫ → у и т. п.).

## Стратегия для 31 вопроса (экзаменационные ответы)

Цель: исчерпывающий ответ строго по учебнику на каждый вопрос, без смешения вопросов и без лишних токенов.

1. **Читать только нужные страницы.** Для каждого вопроса диапазон берётся из `notes/QUESTION_MAP.md`
   (§ → печатные стр. → PDF стр. → листы). Всю книгу целиком не читаем: 246 листов с повторами,
   179 уникальных из 217. OCR-текст (`pdftotext`) используется только как дешёвый поиск «где лежит
   нужный §». Формы, таблицы, цитаты и цифры берутся с картинки.
2. **Один вопрос = один изолированный контекст.** Вопрос решает отдельный свежий исполнитель, который
   не видит остальных вопросов и их ответов. Это единственный надёжный способ «очистить контекст»:
   галлюцинации прошлых вопросов в новый попасть не могут. Исполнитель получает только: текст
   вопроса, диапазон страниц, правила оформления, путь для результата.
3. **Результат пишется в файл** `answers/QNN.md` (черновик ответа + список использованных § и страниц +
   список мест с `⟦?⟧`). В основном контексте остаётся только краткий отчёт «готово / что сомнительно».
4. **Крупные таблицы смотрятся отдельно.** Склонения, спряжения, схемы читаются по 1 странице
   (или половине страницы) в большем разрешении, остальное по 2 страницы на лист.
5. **Проверка формы.** Каждая старославянская форма в ответе сверяется с картинкой (не с OCR). Для вопросов
   с таблицами (14–19, 21–27) делается второй независимый проход: проверяющий открывает те же страницы
   и сверяет каждую форму и каждое утверждение ответа.
6. **Интернет** только если учебник вопрос не покрывает; такие места помечаются отдельно со ссылкой.
7. **Сборка.** Готовые ответы переносятся в общий документ по одному вопросу за вызов, в порядке
   номеров. После переноса статус вопроса отмечается в оглавлении.
8. **Оформление ответа:** первая строка = суть в 3–4 предложения; затем разделы по частям вопроса;
   таблицы для парадигм и сопоставлений; в конце раздела ссылка вида (§ N, с. X). Без воды и пересказа
   того, о чём вопрос не спрашивает.
