## Вопрос 18. Прилагательные качественные, относительные, притяжательные. Именные и местоименные формы прилагательных, их склонение.

**Суть ответа.** По значению прилагательные делятся на **качественные** (свойства, воспринимаемые органами чувств), **относительные** и **притяжательные** (признак по отношению к другим предметам или лицам; у притяжательных — по принадлежности) (§ 230). Форм две системы: **именные** (склоняются как существительные на \*ŏ/\*jŏ в муж. и ср. роде, на \*ā/\*jā в жен.; без значения определённости) и **членные (полные, местоименные)** — именная форма + указательное местоимение \*и (ꙗ, ѥ), слившиеся в одно сложное окончание (§ 216–220).

### 1. Разряды по значению (§ 230–238, с. 240–244)
- **Качественные** — свойства, воспринимаемые органами чувств (новъ, длъгъ). **Относительные** — отношение к другим предметам (железный плуг); **притяжательные** — принадлежность (отцов стол).
- **Корневая основа** (с тематическим \*ŏ или \*ā) — немногие, **все качественные**: новъ (ново, нова), соухъ, любъ, длъгъ, нагъ, босъ. Остальные имеют производную основу.
- Суффиксы: **-ив-, -лив-** «склонный» (лъстивъ, милостивъ); **-ат-, -ит-** «снабжённый» (богатъ, маститъ); **-ьн-** «относящийся» (вѣрьнъ), **-ьн'-ь** (дальнь, отьнь); **-ок-, -ък-** качественные (глѫбокъ, сладъкъ); **-ьск-** относительные (дѣтьскъ, небесьскъ).

### 2. Притяжательные прилагательные (§ 239–242, с. 244–246)
- **-j-** (старейший): члов'ѣчь (от члов'ѣкъ), отьчь, овьчь; новые симон'ь, авраамл'ь. После \*ь — **-ии** [-йj-] «принадлежащий» и «свойственный», чаще от названий животных: рабии, божии, пьсии, коурии.
- **-ов- (-ев-)** (из основ на \*ŭ), самый продуктивный, от муж. имён на \*ŏ, \*jŏ: лъвовъ, кесар'евъ.
- **-ин-** от имён на \*ā/\*jā и \*ĭ: мариинъ, голѫбинъ, гостинъ.

### 3. Именные формы и их склонение (§ 215–217, 228–229, с. 226–229, 241–242)
- Прилагательное согласуется с существительным в роде, числе, падеже; морфологически изменяется как существительное — отсюда **именные** формы. Из тематических гласных сохранились \*ŏ (\*jŏ) — для муж. и ср. рода, \*ā (\*jā) — для жен.
- Окончания при муж. и ср. — как у \*ŏ, \*jŏ (рабъ, село; конь, поле), при жен. — как у \*ā, \*jā (жена, ноша); твёрдый / мягкий вариант: новъ / тошть. Соотношение окончаний то же (новꙑ — тоштѩ, как женꙑ — ношѩ); перед и, ѣ дифтонгического происхождения заднеязычный → свистящий (высокъ: местн. высоцѣ, им. мн. высоци; мъногъ — мъноѕѣ).

| Падеж | Муж. (новъ / тошть) | Ср. | Жен. (нова / тоштꙗ) |
|---|---|---|---|
| **Ед.** им. | новъ, тошть | ново, тоште | нова, тоштꙗ |
| род. | нова, тоштꙗ | = муж. | новꙑ, тоштѩ |
| дат. | новоу, тоштю | = муж. | новѣ, тошти |
| **Мн.** им. | нови, тошти | нова, тоштꙗ | новꙑ, тоштѩ |
| род. | новъ, тошть | новъ, тошть | новъ, тошть |
| дат. | новомъ, тоштемъ | = муж. | новамъ, тоштꙗмъ |

- **Звательной формы нет:** в обращении обычно членная форма им. п. (рабе лѫкавꙑи); у притяжательных — именная.

### 4. Членные (полные, местоименные) формы (§ 218–220, с. 228–232)
**Значение.** Новꙑи = новъ + и, новаꙗ = нова + ꙗ. Местоимение первоначально было **определённым членом**: членная форма указывала на известный собеседнику признак; употреблялась **только как определение или при субстантивации**. **Именные** формы лишены определённости; в **сказуемом** — только они. Притяжательные членной формы почти не имеют.

**Образование (§ 219).** Праславянское: \*и (ꙗ, ѥ) + именная форма в том же роде, числе, падеже; затем слияние в одно окончание (выпадение [j], стяжение):
- им.: \*mǫžь dobrъ jь → [добръјь > добрый] → мѫжь добрꙑи;
- род.: \*mǫža dobra jego → добраѥго → добрааго → добраго;
- дат.: \*dobru jemu → доброуѥмоу → доброуоумоу → доброумоу;
- местн.: добрѣѥмь → добрѣѣмь → добрѣмь;
- жен.: добрꙑѩ (вместо \*dobry jejǫ), добрѣи (вместо \*dobrě jei);
- мн.: односложные окончания именных форм + местоимение: род. добръıихъ (из \*dobrъ jixъ), твор. добръıими (из \*dobry jimi); затем добрыхъ, добрымъ.

**Парадигма** (с. 232–233): добръıи / синии (твёрдый / мягкий), ранние формы без стяжения; «=» — как у муж. (ед.) или ср. (дв., мн.). Стянутые мягкие: синꙗго, синюмоу, синимь.

| Падеж | Муж. | Ср. | Жен. |
|---|---|---|---|
| **Ед.** им. | добръıи, добрꙑ / синии, сини | доброѥ / синѥѥ | добраꙗ / синꙗꙗ |
| вин. | добръıи / синии | доброѥ / синѥѥ | добрѫѭ / синѭѭ |
| род. | добраѥго / синꙗѥго | = муж. | добрꙑѩ / синѩѩ |
| дат. | доброуѥмоу / синюѥмоу | = муж. | добрѣи / синии |
| твор. | добръıимь / синиимь | = муж. | доброѭ / синѥѭ (добрѫѭ / синѭѭ) |
| местн. | добрѣѥмь / синиѥмь | = муж. | добрѣи / синии |
| **Дв.** им.-вин. | добраꙗ / синꙗꙗ | добрѣи / синии | = ср. |
| род.-местн. | = ср. | доброую / синюю | = ср. |
| дат.-твор. | = ср. | добрꙑима / синиима | = ср. |
| **Мн.** им. | добрии / синии | добраꙗ / синꙗꙗ | добрꙑѩ / синѩѩ |
| вин. | добрꙑѩ / синѩѩ | добраꙗ / синꙗꙗ | добрꙑѩ / синѩѩ |
| род., местн. | = ср. | добръıихъ / синиихъ | = ср. |
| дат., твор. | = ср. | добръıимъ, добръıими / синиимъ, синиими | = ср. |

**Взаимодействие с местоимениями (§ 220).** Окончания членных форм близки окончаниям неличных местоимений, поэтому их называют **местоименными**. Взаимовлияние: тꙑи, кꙑи — как добрꙑи; у членных род. живого (как того), дат. дроугомоу (как томоу).
